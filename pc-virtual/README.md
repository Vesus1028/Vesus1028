# PC Virtual (VesusOS)

Um "computador" que roda inteiro no navegador: área de trabalho, janelas, barra de tarefas e menu iniciar.

## Como usar

Abra o arquivo `index.html` no navegador (dois cliques nele). Não precisa instalar nada.

Para publicar na internet de graça, ative o **GitHub Pages** no repositório
(Settings → Pages) e acesse `.../pc-virtual/`.

## Apps incluídos

| App | O que faz |
|---|---|
| 📁 Arquivos | Navega pelas pastas, cria/renomeia/exclui arquivos e pastas |
| 📝 Bloco de Notas | Edita e salva textos (Ctrl+S), baixa como .txt |
| 💻 Terminal | Comandos tipo Linux: `ls`, `cd`, `cat`, `echo`, `mkdir`, `rm`, `mv`, `open`, `calc`, `neofetch`… (digite `help`) |
| 🧮 Calculadora | Funciona com mouse e teclado |
| 🎨 Paint | Desenha, apaga, salva em Imagens ou baixa como PNG |
| 🌐 Navegador | Abre sites dentro de uma janela (alguns sites bloqueiam isso) |
| ❌ Jogo da Velha | Contra o computador |
| ⚙️ Configurações | Papel de parede, cor de destaque, nome de usuário, restaurar padrão |

## Dicas

- Arraste as janelas pela barra de título; dois cliques maximizam; redimensione pelo canto.
- Botão direito na área de trabalho e no explorador abre menus de opções.
- Arquivos e configurações ficam salvos no próprio navegador (localStorage).
